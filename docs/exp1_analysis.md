# Experiment 1: Interpolation Search

## Objective
Implement and analyze interpolation search for sorted data.

## Algorithm
Interpolation search estimates the likely position of the target using the value distribution in the sorted array.

## Time Complexity
- Best case: O(1)
- Average case: O(log log n) for uniformly distributed data
- Worst case: O(n)

## Space Complexity
- O(1)

## Applications
Useful for searching within uniformly distributed sorted arrays such as database indexes.
