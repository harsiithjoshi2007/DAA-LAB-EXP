# Experiment 4: Dijkstra's Shortest Path Algorithm

## Objective
Implement Dijkstra's single-source shortest path algorithm.

## Algorithm
The algorithm repeatedly picks the unvisited node with the smallest tentative distance and relaxes neighboring edges.

## Time Complexity
- With a min-priority queue: O((V + E) log V)

## Space Complexity
- O(V + E)

## Applications
This algorithm is widely used in routing, network design, and shortest-path computations in weighted graphs.
